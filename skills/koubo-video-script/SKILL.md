# 口播视频脚本

目标：写出一份说出来顺口、能直接驱动剪辑的脚本。它和公众号文章不是一回事：文章写给眼睛，脚本写给嘴和画面。

## 先确认创作者设定

值还是【待填】时，先问用户，再把答案写回本文件。

| 项目 | 值 |
|---|---|
| 创作者名字 | 【待填】 |
| 结尾署名 | 【待填，例如“OK，今天就分享到这里，我是 XX，更多 AI 应用我们下期再见。”】 |
| 主要领域 | 【待填，例如 AI 工具、职场效率】 |
| 发布平台 | 【待填，例如小红书、视频号、抖音】 |
| 口头禅或固定说法 | 【可选】 |

## 开写前先确认

1. **类型**：快讯观点、工具教程或榜单盘点。
2. **真实材料**：我亲手做了什么？有哪些录屏、结果、数字和一手来源？
3. **一句话**：观众看完只记得一件事，这件事是什么？说不出来就先别写。
4. **时长**：按每秒约 6 字估算，60 秒约 360 字。写完后必须念一遍，以实际时长为准。

缺材料时列出缺什么，不要编。没做过的事写成“我准备试”或“资料里说”，不写成“我测过”。

## 所有类型都遵守

### 句子

- 用老师教朋友的口吻：主要讲实际用的方法和为什么这么做。走过的弯路，值得提醒对方的就说一句（“别用……，我试过……”），没有提醒价值的不说；不写对观众没用的技术细节。
- 小红书字幕不出现品牌词和敏感词（例如“公众号”可以写成“👸号”）。
- 不说品牌名：办公软件里的表格说“多维表格”，AI 工具统称“AI”。
- 只讲推荐的一种方案，不铺开备选方案。
- 按字幕行写，每行约 8–14 字，一行一口气。
- 先说人话，再说术语。术语第一次出现时顺手翻译。
- 多用“我”交代动作和判断，用“你”带观众进入场景。
- 允许“其实、所以、比如、说白了”，但不要句句带。
- 删掉“那……呢”这类无信息的气口词，除非它确实在制造停顿。
- 用具体的产品、数字和动作，不用“赋能、闭环、王炸、封神”。

### 开头

前 3 秒只做一件事，从下面选一种：

- **亮结果**：先给做成的东西，再说怎么做的。
- **说代价**：我花了多少钱、时间或轮次，才换来这个结论。
- **戳错法**：指出一个常见做法错在哪，但要给得出依据。
- **反差**：大家以为是 A，原文或实测是 B。

不用“大家好，今天我们来聊聊”开场。不用没有依据的恐吓。

### 中段

- 每段只回答一个问题。
- 至少讲一次真实踩坑：我以为是什么问题 → 试了什么 → 真正的问题是什么。
- 每个结论旁边要有证据：录屏、数字或来源。
- 区分实测、官方说法和我的推断，念出来也要听得出区别。

### 结尾

顺序固定：一句话判断 → 这件事的限制 → 观众下一步 → 署名。

署名用上面设定的结尾署名。

只有确实提供了文档或模板时，才说“都放在文档里了”。

## 三种结构

### 快讯观点（45–75 秒）

1. 反差钩子。
2. 发生了什么：时间、主体、来源。
3. 网传和原文对照。
4. 我的判断和依据。
5. 还不知道什么，以及为什么现在不能下结论。
6. 抛一个两边都能答的问题。

硬规则：每个事实都能追到一手来源；“可能”不能写成“已经”；争议双方篇幅对等；涉及利益相关方时要说明。

### 工具教程（90–180 秒，长版 5–8 分钟）

1. 亮结果。
2. 观众卡在哪，这条解决什么。
3. 前提：费用、版本、需要什么。
4. 编号步骤：每步一个动作、一个可见结果，必要时加一句踩坑。
5. 限制：哪些情况不适合。
6. 结果和入口。

长版先用一句话预告有几部分，每部分开始时点出序号。

### 榜单盘点（60–180 秒，长版 8–12 分钟）

1. 我的代价和资格：为什么我有资格选。
2. 筛选标准：说清怎么选，有商业合作要说明。
3. 固定分栏：全片只用一套，例如“首选 / 平替 / 开源”。
4. 每项固定三句：是什么、为什么留下、代价或短板。
5. 每个大类结束放一张可截图的小结。
6. 最后给选择建议，不止罗列。

## 输出格式

用这个表格交付：

| 秒数 | 口播（按字幕行） | 画面类型 | 素材 / 上屏字 | 证据来源 |
|---|---|---|---|---|

画面类型只从下面选：

| 类型 | 用在什么时候 |
|---|---|
| `人-全屏` | 钩子、判断、踩坑、结尾 |
| `人-半屏` | 边说边看素材、原文或案例 |
| `人-小头像` | 操作录屏、页面演示、长内容 |
| `列举` | 三项以内的关键词逐个上屏 |
| `巨字` | 全片最重要的数字或一句话 |
| `对比` | 网传和原文、之前和之后、方案 A 和 B |
| `榜单卡` | 榜单条目或大类小结 |

最后附上：总字数、预估时长、缺失素材清单。

## 交付前检查

- 把脚本念一遍，拗口的地方改掉。
- 只听声音能懂吗？只看画面和字幕能懂吗？
- 标题和钩子的承诺兑现了吗？
- 每个“我”做过的事都有真实依据吗？
- 限制和代价说了吗？
- 连续 3 行以上没有新信息的，删掉。

## 样本说明

规则提炼自 13 条参考视频的画面和屏幕字幕（OCR，含识别错误），未核对原始音频。句子规律只提炼结构，不抄原句。第一版尚未用真实成片验证，每做完一条就把问题写回这里。
