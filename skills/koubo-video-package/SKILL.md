# 口播包装

输入：口播原片、素材文件夹、背景音乐。输出：竖屏成片和封面。

按下面的顺序做，每个标着“确认”的步骤都先让用户看过再往下走。

## 先确认创作者设定

开始前读取下表。值还是【待填】时，先问用户，再把答案写回本文件，下次就不用再问。

| 项目 | 值 | 用在哪 |
|---|---|---|
| 创作者名字 | 【待填】 | 结尾署名、封面 |
| 结尾署名 | 【待填，例如“我是 XX，我们下期再见”】 | 最后一屏 |
| 主色 | `#fff6bb` 浅黄（可改） | 背景、封面 |
| 强调色 | `#ff0808` 亮红（可改） | 关键词、标题 |
| 发布平台 | 【待填，例如小红书、视频号】 | 标题字数、品牌规则 |
| 字幕 | 中英双语，英文字号小（可改成只要中文） | 字幕层 |
| 外貌要点 | 【待填，例如发型、眼镜】 | 数字人定妆照，防止模型乱改 |

## 准备

第一次使用先运行 `scripts/setup.sh`。所有依赖都装在 `~/.cache/koubo-video`（可用 `KOUBO_VIDEO_HOME` 改位置）。

绝不要把依赖装进全局 Python：安装失败时不要回退到裸 `pip install`。

每条视频建一个工作目录，比如 `制作/02/`，放 `edit.json`、`scenes.js`、`page.html`（从 `template/page.html` 复制，把 `SKILL_TEMPLATE` 改成模板的相对路径）。

中间文件（帧、抠像）放临时目录，可以重新生成，体积很大。

## 每条视频的完整交付

做完视频不算结束，必须一起交付：

1. 成片
2. 爆款标题（小红书限 20 字，给 3–4 个，标出推荐）
3. 平台正文，带当前活动要求的话题
4. 封面标题和封面提示词（基于 `references/cover.md`）
5. 给生图 AI 的素材文件和清单，说明每个文件的用途

参加活动时，把活动规则写成发布前自查清单，并确认时长、话题和日期。

## 文章来源

选题来自公众号或网页文章时：

1. 抓正文和图片，图片下载到 `素材/<编号>/文章配图/`，逐张查看。
2. App ID、Secret、链接和别人的内容，上屏前必须模糊。
3. 脚本只用文章里的事实，补充的内容要标出来让用户确认。

网站出现验证页时，不要绕过，请用户验证或提供正文。

## 流程

1. **转写。** `scripts/transcribe.py` 输出逐字时间轴。先看用户实际说了什么，不要按稿子猜。
2. **降噪（确认）。** `scripts/denoise.py` 用 DeepFilterNet 在本地处理，生成 `强` 和 `保留底噪` 两版。ffmpeg 基础降噪实测基本无效，不要用。用户听完选一版。
3. **粗剪。** 把重说、口误写进 `edit.json` 的 `remove`，运行 `scripts/rough_cut.py`。词的时间戳可能不准：有疑问的剪点要看音量包络，必要时用 `last_segment_start` 修正。成片后再转写一次，确认重说已消失。
4. **抠像和人脸跟踪。** 用 `seg`（macOS Vision）和 `face`。先做 3 帧样片看边缘（确认）。边缘规则见 `references/style.md`。
5. **写场景。** 在 `scenes.js` 里写 `SCENES` 和 `SUBS`。时间用原片秒数，引擎会自动换算。字幕按实际口播校对，时间有疑问的词要提示用户。
6. **样帧（确认）。** `scripts/render.py --at 时间列表` 出关键帧，先自查再给用户。
7. **完整渲染和混音。** `scripts/beat_align.py` 选音乐起点，`scripts/render.py` 出无声视频，`scripts/finish_audio_v4.py` 混音（音效目录见仓库 README）。
8. **质检。** 查响度（目标 -14 LUFS）、重新转写、逐段抽帧，确认文字没有出界。声音和观感要明确告诉用户你无法亲自判断。
9. **封面（确认）。** 见 `references/cover.md`。

不想真人出镜时，先按 `references/avatar.md` 做数字人源片，再从第 4 步接着走。

## 必须遵守

- 发小红书的内容不出现品牌名：口播、字幕、标题、正文和封面都不写具体的办公软件或 AI 工具名，统一说“多维表格”“AI”。画面里露出的品牌要模糊或遮挡（录屏用 `scripts/rec_frames.py`）。
- 同一件事有多种方案时，只讲推荐的一种。
- 参考视频的画面上屏前一律模糊，不标注作者。
- 说“不是我剪的”“全自动”这类话之前，确认实际情况。有手工修改就要改口。
- 用户说视频不用改时，不要重渲或重混已定稿的版本。
- 中间文件和原片不进仓库。
- 真实素材不少于 AI 内容：优先用录屏、手工截图和真实产物，截图放大到接近满宽。细则见 `references/materials.md`。
- 抖镜只抖素材，不抖人和房间；每步结尾的清单停顿不超过 1.5 秒，而且要有动画。
- 用真实数据重画的画面不能说成截图；没用过的工具不截图冒充。
- API key 只从环境变量读，绝不打印、不写进文件。
