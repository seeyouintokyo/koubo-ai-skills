# 动效升级方向

## 现状和差距

第一条（v3）的语言偏“卡通手账”：粗黑边、硬阴影、回弹、震屏、斜切转场。

对标视频的语言更接近苹果风：

| 项目 | 现在 | 目标 |
|---|---|---|
| 进场 | 回弹、放大 2.3 倍 | 弹簧不回弹，透明度加模糊，短距离位移 |
| 转场 | 黑色斜切、整屏色块 | 模糊叠化、圆形遮罩收缩、人物变形 |
| 卡片 | 粗黑边、硬阴影 | 大圆角、柔阴影、毛玻璃、高亮聚焦 |
| 大字 | 砸入、震屏 | 柔光发亮、藏在人后、缓慢漂移 |
| 界面演示 | 整张静止 | 其他区域压暗，只亮重点；光标引导 |

实际拆帧看到的手法（只学手法，不抄画面）：

- 全屏人物通过圆形遮罩缩到小头像位置。
- 前后两个画面同时模糊，再叠化切换。
- 界面压灰，只保留一条高亮区域。
- 文字带柔光，放在人物后面。

## 音效

测量结果（音效起点的频谱重心分布）：

| 视频 | 每分钟音效起点 | 音色跨度（p90/p10） |
|---|---|---:|
| 第一条 v3 | 44 | 1.3 |
| 对标 A | 9 | 2.4 |
| 对标 B | 17 | 2.8 |
| 对标 C | 27 | 2.4 |

结论：太密、音色太少。用户听到的“啾啾啾”“咚咚咚”就是这两种合成音。

## 怎么做

1. **换真实音效库。** 优先 CC0：Kenney Interface Sounds、Lots of Sounds、Freesound 的 CC0 分类。下载前确认来源和授权。
2. **按事件分类。** 转场、卡片、关键词、数字、光标各用一组，每组 3–5 个变体，不重复播放同一个。
3. **减量。** 每分钟控制在 15–25 个，只给重要动作配音。
4. **转场库。** GL Transitions（大多为 MIT）可以作为遮罩和叠化的来源；简单的模糊和圆形遮罩直接用 CSS 就能做。
5. **引擎改造。** 把 `reveal()` 拆成主题：保留 `playful`（现状），新增 `soft`（苹果风）。

每项都要先出 3–5 秒样片，让用户看过再推广到全片。

## 第二轮结论（2026-11-06）

- 柔和的苹果风试过，用户觉得冲击力不够：发光字发糊、字体不活泼、转场看不出来、章节页没动势。保留 v3 的冲击力为底（theme-v4.css + engine-v4.js）。
- v4 在 v3 上加了：砸字后的衰减回弹、撞击震屏、全屏画面的轻微手持晃动、两个全屏镜头硬切时的暖白闪光、章节数字回弹、中英双语字幕。
- 音效换成 Kenney Interface Sounds（CC0），按事件分配：点击类给卡片和标签、drop 给砸字、maximize/minimize 加合成嗖声给转场、confirmation 给章节、glass 给闪光硬切。下载方法见仓库 README。
- 参考：video-shotcraft（Apache-2.0，手法可借鉴代码）；video-talkcraft（非商业许可，只参考思路）。
- 柔和版文件（theme-soft.css、engine-soft.js）保留，可用于需要安静气质的内容。
