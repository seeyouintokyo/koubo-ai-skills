# 拆解对标视频

## 步骤

1. 用 ffmpeg 抽总览帧（每条约 24 张）和前 6 秒钩子帧。
2. 用 `ocr` 按每秒 1–2 帧读屏幕文字，再用 `scripts/parse_ocr.py` 合并成带时间的字幕。OCR 含错字，只看规律。
3. 统计切镜、字幕长度、每分钟屏幕文字。这些是趋势，不要当精确数字引用。
4. 找变化最大的时刻，抽连续帧看转场。
5. 用 YDIF（帧差）比较动感。平均值看总量，中位数看“有没有停住”。

## 第一次拆解的结论

- 动感来自“人的大小跟着内容变”和持续有新元素，不是切镜多。
- 字幕每条约 8–12 字，停留 1–2 秒。
- 脚本结构见 `koubo-video-script`。
- 第一条 v2 的平均帧差和对标接近，但中位数只有 0.83，对标是 1.8–2.6：动作之间画面停住了。
