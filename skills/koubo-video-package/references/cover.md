# 封面

## 原则

保留淡黄色，也能显得高级。关键是减法，不是加元素。

- **底色：** `#fff6bb` 为主，最多加一层很淡的白色光晕。
- **文字：** 只用黑色和亮红色 `#ff0808`。不用描边字、渐变字、发光字。
- **层级：** 两行主标题加一行小字，最多三层信息。主标题占满宽度。
- **一个主角：** 一个人，加一个主题大道具。窗口和小元素用来填满层次，不要贴纸堆叠。
- **去掉廉价感：** 不用笔刷、爆炸线、网点、彩色小图标、硬阴影色块。
- **真实光影：** 人物和卡片用柔和投影，让它们浮在底色上。
- **人物：** 用真实照片，提亮脸部，表情明确，不要 AI 美化成另一个人。
- **一致性：** 每期的标题位置、字重和人物位置保持一致，放在一起才有品牌感。

## 默认构图：大字压顶

人物不能抢主题。比例大致是：

- 上方 20%：一行超大标题，占满宽度，最好 3–5 个字。
- 中间 40%：人物居中，头顶压住标题下沿。身后左右叠放倾斜的界面窗口，一直延伸到画面边缘，不要留纯色空白。
- 下方 40%：表达主题的大道具，比如时间轴、代码窗口、数据图。
- 人物两侧最多 3 个小标签，说明这期的具体内容。

道具尽量用这条视频的真实内容，不用假界面。

## 代码生成

运行 `cover/make_cover.py config.json 输出.png`。

默认用 `"layout": "stage"`，字段：`person`、`face`、`strip`（底部画面条）、`kicker`、`title`、`panel_title`。可选：`title_size`、`person_top`、`person_height`、`panel_height`、`playhead_top`。标签和时间轴内容目前写在 `cover/template_stage.html`，每期要改。

上下分栏的旧版式，config 字段：`person`（抠像 PNG）、`screen`（卡片图）、`face`（归一化的人脸中心和大小）、`kicker`、`line1`、`line2`、`sub`。可选：`feather`、`face_light`、`size1`、`size2`、`top2`、`top_sub`、`person_right`、`person_height`。

注意：人物碰到原画面边界会露出硬边，要让卡片盖住。

## 通用提示词（用其他 AI 生图时）

上传一张人物照片，每次只替换第一行标题：

```text
【标题】AI动效包装

生成一张 3:4 竖版中文短视频封面，1080×1440。画面要饱满、有层次，不要留大块空白。

构图（从前到后叠放）：
- 标题：画面最上方，一行超大字，占满画面宽度，左右只留很小的边距。
- 人物：放在画面中央偏上，上半身占画面高度约 55%，头顶压住标题下沿。一只手伸向前方，托着、指着或拿着主题道具，表情惊讶或兴奋，看向镜头。
- 主题道具：根据标题自动设计一个大道具，占画面下方约 40%，比如剪辑时间轴、代码窗口、数据图、手机界面。道具有透视，挡住人物胸部以下，和人物的手有互动。
- 背景层：人物身后左右各放一块倾斜的界面窗口或主题元素，一直延伸到画面边缘，填满人物两侧。
- 漂浮元素：人物周围放 2–3 个与主题相关的小图标或半透明小卡片，有大小和远近变化。

人物：严格使用参考照片里的人，五官、脸型、发型和眼镜都不能改，不要美颜成另一个人。保持真实摄影质感和自然肤色，脸部不要过亮，光线要和场景融合。

文字：标题用最粗的中文黑体，字距紧凑，纯亮红色 #ff0808。全图只允许出现【标题】这一段可读文字，一字不改。道具和窗口里不要出现文字、乱码或假字，用色块和线条表示内容。

配色：背景是浅黄 #fff6bb，所有空隙都透出这个颜色。除照片本身外，道具和窗口只用白色、黑色、浅黄和亮红色 #ff0808。

质感：精致的商业海报，有景深和柔和投影，像高级的三维合成。手机缩略图里也能一眼读清标题。

不要：大块空白、人物悬在纯色背景上、笔刷、爆炸线、网点、贴纸、描边字、渐变字、水印、平台图标、其他任何文字。
```

AI 生图常见的问题是把人改掉、字变小。如果标题总是生成不好，就让它只生成人物和道具，标题和底色用代码合成。

## 用 API 直接生成

生图 key 放在环境变量里（例如 `OPENAI_API_KEY`，用兼容接口时再配 `OPENAI_BASE_URL`）。读取时不要打印 key。没有 key 就只用代码合成。

1. 上传定稿定妆照作为参考图，用上面的通用提示词，只换标题。
2. 一次只生成 1 张，看过再决定要不要重来。
3. 生成后检查：脸是不是本人（AI 常把人换成另一张脸）、标题字有没有错、有没有出现品牌名和假字。
   脸不像就改用代码合成：AI 只出背景和道具，人物用真实抠像，标题用代码排版。
4. 交付时说明封面是 AI 生成还是代码合成。
