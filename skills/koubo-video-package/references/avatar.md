# 数字人

用于不想真人出镜的段落。每次生成前先报价，用户确认后再扣积分。

## 流程

| 环节 | 用什么 | 做法 |
|---|---|---|
| 声音 | MiniMax 声音克隆（`avatar/minimax_voice.py`） | 样本用降噪后的干净口播，30 秒以上更好。key 放在环境变量 `MINIMAX_API_KEY`，绝不打印。台词合成后先转写核对 |
| 定妆照 | 生图模型（Renoise 或 LibTV 上都有），用真实照片做参考 | 参考图只用本人真实照片，一次生成 4K 竖屏 |
| 对口型 | 视频模型：定妆照 + 配音 | 选哪个模型见下表 |
| 换回原声 | `avatar/align_voice.py`（Whisper + ffmpeg，本地跑） | 模型自己配音时用：按停顿逐句变速，对齐到视频里同样两个字之间 |
| 拼片 | ffmpeg | 只给露脸说话的镜头做口型，整条加速 1.2 倍 |

## 对口型模型怎么选

| 模型 | 声音从哪来 | 嘴跟着什么动 | 要不要换回原声 |
|---|---|---|---|
| OmniHuman 2.0 | 你给的音频 | 你给的音频 | 不用，口型最准（按原理）；720p，表情偏外放 |
| Seedance 2.0 / 2.5 | 模型自己重新配，你的音频只当参考 | 它自己配的声音 | 要，个别地方会偏 |
| Wan 3.0 | 模型自己配（可关掉） | 它自己生成 | 要；画面最真实 |

- 想省事、口型准：用 OmniHuman 2.0，一张人像加一段 4–300 秒的音频。
- 用 Seedance：台词必须逐字写进提示词，否则会自己改词；生成后用 `align_voice.py` 换回克隆声。拉伸超过 25% 的句子脚本会标出来，要人耳确认。
- 同一平台不同入口支持的输入不一样，先查模型说明（能不能输入音频、只收首帧还是收参考图）。

## 定妆照规则

- 外貌要点（发型、眼镜等）写死在提示词里，见 `SKILL.md` 的创作者设定，不要让模型随意改。
- 参考图只用真实照片。AI 写真会把脸带偏。
- 脸有问题时从原始照片重新生成，不要在生成图上反复修改，改得越多越糊。
- 照片里不要加颗粒和噪点，视频模型会把它放大成皮肤上的脏点。脸用白色柔光打，彩色灯只留在背景和发丝边缘。
- 上身基本坐直，只轻微侧转（约 30 度），头转回看镜头；前倾太多像探头。
- 手放在胸前做说话手势，不碰脸，下巴和嘴要完整露出。
- 胸部以上取景，头上留空间，机位略偏一侧、略低。
- 桌上道具要有个人痕迹（有图案或用旧的马克杯、笔记本电脑、书），随意摆放。纯白马克杯、太整齐的桌面一看就是 AI。
- 景深像真实手机：前景基本清晰，背景轻微虚化。不要光斑。
- 想要更真实：背景简单、白天自然光、落地窗，比夜景霓虹灯房间更像真人。窗外不要整齐排列的楼和灯。
- 用 4K 生成：人缩成小头像后脸只占几百像素。
- 一条视频一个机位和姿势就够了，变化靠手势和包装里的画幅切换。

## 场景建议

| 场景 | 适合 |
|---|---|
| 纯色极简 | 半屏、小头像（会抠像），最清晰 |
| 书房落地窗 | 教程、日常分享 |
| 写字楼高层 | 工具、观点 |

## 省钱

- 只给露脸说话的镜头（全屏、半屏）生成对口型；小头像镜头用定妆照静帧加闪动光圈（scene 加 `still: 1`）；讲操作的镜头可以不出人（`p: 'none'`）。
- 生成前先报价。参考价（某平台实测）：定妆照约 23 积分一张；7 秒对口型约 84–98 积分。第一次做时改了 5 版照片，约 340 积分才得到一段可用的。

## 剪辑

- 按旁白顺序把对口型片段、静帧加对应旁白拼成一条源片，整条加速 1.2 倍（画面和声音一起，口型不会错位），再走正常流程：抽帧、人脸、抠像、`scenes.js`。生成和对齐都按原速做，最后再加速。
- 源片是 9:16 时在 `scenes.js` 里设 `DATA.aspect = 16 / 9`，并调 `LAYOUT` 的 `dw`。
- 拼片时 zsh 会把 `"[$i:a]"` 里的 `:a` 当成路径修饰符，写成 `${i}`。
- TTS 读数字容易出错（例如“1080p”），写成读法再合成。
